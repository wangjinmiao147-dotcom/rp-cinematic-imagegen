# RP电影配图 v2.9.63：多人物参考图、内置工作流与本地像素控制

一张故事卡可管理多个独立人物，由AI判断谁实际入镜并上传对应主参考图。支持真实姓名/别名、人物区域标注、单角色LoRA，以及ComfyUI内置SD/LCM/Qwen工作流。自定义像素与步数在主设置区直接选择，原有自定义工作流继续可用。

修复Gemini思考草图误选、主参考图身份说明遗漏、参考图按钮重叠、省略证据核验与错误提示。默认错误报告不含剧情、角色名、密钥或图片，仅下载到本机。
