# 清晰绘制与姿态参考

在本地 Qwen 的原图参考模式中，高级参数“清晰绘制，最终512”对普通剧情使用一次整图生成，再由浏览器缩小完整画面。步数、CFG、随机种子和桥接温控沿用当前设置，参考处理使用 detail 档。该选项默认关闭；关闭后继续使用已选的直接绘制分辨率与参考处理档。开启时这两项由清晰模式管理，原来的值仍保存供关闭后使用。镜面、倒影场景继续按原保存档位绘制。

| 当前画幅 | 内部绘制 | 最终图片 |
|---|---|---|
| 16:9 | 1024×576 | 512×288 |
| 9:16 | 576×1024 | 288×512 |
| 1:1 | 768×768 | 512×512 |
| 4:3 | 1024×768 | 512×384 |
| 3:4 | 768×1024 | 384×512 |
| 2.39:1 | 992×416 | 512×214 |

超宽内部尺寸按引擎要求对齐，最终按完整画面缩放到最接近目标画幅的整数像素；没有裁去图像边缘。桥接返回错误尺寸、浏览器无法解码或生成取消时，不将内部大图当成最终512图片保存。

提示词依照 [Qwen 2.1 官方编辑规范](https://github.com/QwenLM/Qwen-Image-2.1/blob/main/prompt_rewrite/prompts/system_prompt_edit.txt) 明确每张图的身份用途，保留本张剧情动作、当前服装、排除项和视角。清晰路径使用较短的自然语言，并把具体人物、支撑及手部动作放在通用说明之前。参考原姿势、背景和手持物不自行成为剧情事实；没有剧情依据不新增心理气泡。

姿态参考借鉴 [Fisher Pose 的 Qwen 多图映射方法](https://github.com/Work-Fisher/ComfyUI-Fisher-Pose/blob/main/qwen_bridge.py)：身份图按人物编号，几何参考最后发送，并说明人偶左右位置对应谁。这里独立生成简单关节参考，没有安装 ComfyUI、下载其模型或执行外部仓库代码。

当前自动姿态引导只覆盖明确的双人站立、主要人物背靠洗手台且双手在腹部附近、另一人物向前俯身并单手递物或伸手的范围。仅接受前斜侧视角或未指定机位；指定左右手保留，未指定时不将引导的默认选择写成剧情事实。镜面、坐卧、局部人物、交叉站姿、明确弯腰后仰、非人形特征等不套用这张固定姿态。其他场景仍采用自己的原动作与提示路径；这不是任意剧情的姿态求解器。

镜面保留 v2.9.55 的同一身体反射几何及原绘制尺寸。它仅覆盖单人竖直墙镜、后方偏左或偏右机位、肩高单掌接触且另一臂垂下的限定情况。镜面与倒影不启用高分辨率清晰路径；复杂动作与手部仍需逐图核对。
