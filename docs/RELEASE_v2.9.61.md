# v2.9.61 维护修复与错误报告

基于 GitHub v2.9.57，包含 [v2.9.60 维护批次](RELEASE_v2.9.60.md) 的全部修复，新增一键导出错误报告。

修复并发图库保存丢记录、排队消息或会话变化后继续出图、图库异步窗口失效、角色形象主参考用途错误、ComfyUI 上传及执行错误处理、Gemini 模型路径与空响应、局域网 HTTP 参考图读取及自动检测取消竞态。三类生成入口共用可取消队列，参考图库使用稳定记录标识和原子修改。

ComfyUI 单次历史查询超时不会被误判为用户取消，会在总体期限内继续获取已提交任务；真正取消仍立即停止。

## 使用

在扩展设置的“错误报告”卡片或悬浮工作台点击“导出错误报告”，浏览器会下载一个 `rpig-error-report-v2.9.61-时间.json` 文件，便于发送给维护者。导出不请求图片模型，不上传报告。

报告合并本机最近 5 条诊断及当前聊天最近 20 条消息保存的生成诊断，去重后最多 10 条。普通生图、局部精修、人物形象任务均保存诊断；自动场景分析仅收集仍有效任务的实际失败，避免成功检查挤走失败记录。没有记录时仍导出版本及配置概况。

## 内容与隐私

默认仅导出版本、后端类型、配置选项枚举、任务状态、模式、失败阶段、已知错误码、静态摘要、起止时间、总耗时、图片尺寸与参考图计数。任意原始诊断字段不能自动进入报告；未知错误码统一为 `UNKNOWN_ERROR`。旧记录没有起止时间时不推测耗时。

默认不导出剧情、提示词、角色名、原始服务错误、请求标识、模型名、接口地址、本机路径、参考图资料或图片。需要进一步排查时可手动勾选“附带文字诊断（含剧情与提示词）”；文字包含分析原文、提示词和原始错误，配置密钥及常见凭据、URL、图片 data/blob 内容会剔除，单段最多 4000 字符，过长输入直接省略。勾选后分享前仍可打开 JSON 查看自己选择附带的剧情文字。

新版在保存诊断时即剔除密钥及其编码变体，换配置后不会回显旧密钥。旧版生成的记录没有新版脱敏标记，其文字会省略，仍可导出结构化状态和已知错误码；复现问题后新记录即可附带文字诊断。

## 兼容与验证边界

诊断存储损坏不会阻止导出；localStorage 不可用时当前页面保留最近诊断。页面刷新会清空内存记录。文件下载使用本地 JSON Blob，完成后释放 URL；下载受浏览器或系统下载策略控制。源代码与模拟浏览器下载、存储和任务回归可验证报告结构和隐私过滤，尚未进行手机实机与收费模型验收。
