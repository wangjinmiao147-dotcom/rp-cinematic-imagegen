# v2.9.60 维护修复候选

此维护批次以 GitHub v2.9.57 为基准，处理可复现的运行与存储问题，随 v2.9.61 发布；未单独发布 v2.9.60。

## 修复范围

- 参考图在局域网 HTTP 环境缺少 Web Crypto 时不再报错；重复参考保留主身份用途，导出保留各记录元数据。
- 图库读改写合并为事务，避免并发保存丢记录；事务中止、读取失败和连接关闭统一处理。
- 参考图迁移稳定 refId，主图选择、用途、启用状态、删除和导入采用原子修改。
- 自动检测重置取消旧请求，旧回调无法释放新任务锁或覆盖新状态。
- 消息在排队或请求准备期间删除、编辑、滑动或切聊时不再继续生图；任务使用独立配置快照。
- 角色三视图与全身形象传递主身份参考，并和普通生成、局部精修共用可取消队列。
- 图库和大图单实例管理，切聊天会关闭旧窗口并丢弃延迟返回；删除后刷新当前聊天。
- ComfyUI 上传失败、缺图像节点、提示词节点冲突、执行失败和空结果均明确报错，不使用旧图继续。
- Gemini 模型名前缀和空图片响应处理修正；数字角色名如 2B、9S 保留完整身份。
- 可选本地服务在冷却采样期间取消后不提交推理或卸载模型。
- 移除无调用的入口函数和导入，自动发现测试文件并补全运行文件打包清单。

## 验证与边界

回归使用虚构剧情、模拟服务与 IndexedDB，执行生产任务、请求适配器及存储代码。测试与 ZIP 文件检查证明这些代码路径的行为；未新增收费模型请求、私人剧情生成或手机实机验收。

“从图库和聊天移除”移除索引和消息挂载，服务器图片文件仍保留。参考库、图库与酒馆聊天采用不同的持久化机制，不能保证跨三者的事务原子性。

基础插件仍无需 npm 运行依赖。开发执行 `npm ci`、`npm test`、`npm run check`、`npm run build`；可选本地服务先执行 `npm ci --prefix tools/local-scene-llm`，再执行 `npm run test:local` 或 `npm run test:all`。
